# World Monitor на български

Личен fork на [koala73/worldmonitor](https://github.com/koala73/worldmonitor) — табло в реално време за световните събития: карта и 3D глобус, конфликти, бедствия, пазари, живи новини и AI обобщения.

Целта на fork-а е World Monitor да е удобен за ползване на български: български интерфейс по подразбиране, български източници на новини, без платени заключени части.

Оригиналното описание (на английски) е в [README.md](README.md).

## Какво е променено спрямо оригинала

| Какво | Състояние |
|---|---|
| Интерфейс на български по подразбиране (без `?lang=bg`) | готово |
| Часовник в местно време и български формат (`ср, 04.11.2026, 13:43:41`) | готово |
| Платените части (лента „Pro“, „Надстройка“, „Влез“, заключени панели) са скрити | готово, превключвател `HIDE_PREMIUM` в `src/config/fork.ts` |
| Довършен превод, включително долното меню | готово |
| Български източници: БТА, Капитал, Клуб Z, Сега, Nova, 24 часа, Дарик, Mediapool (+ Дневник от оригинала) | готово, включват се сами при български интерфейс |
| Арменски източници: News.am, Asbarez, Hetq | в каталога, но изключени по подразбиране (пускат се от Настройки) |
| Подробни граници на държавите (Natural Earth 50m) вместо опростените | готово, нужна е настройка в `.env.local` (виж по-долу) |
| AI обобщенията пишат „на Bulgarian“ вместо „на BG“ | готово, не е проверено с истинско обобщение |
| Нов вид, 3D глобус God's Eye, сателитна карта, изгледи „България“ и „Армения“ | предстои |

## Пускане на Mac

Нужен е Node.js 24 (версията е в `.nvmrc`).

```bash
cd ~/"Desktop/Developer/personal projects/worldmonitor"
npm ci
echo "VITE_COUNTRY_OVERRIDES_URL=/data/country-boundary-overrides-world.geojson" > .env.local
npm run dev
```

Vite показва адреса в терминала. Обикновено е `http://localhost:3000`, а ако портът е зает — следващият свободен (напр. `3001`):

```bash
open -a Safari "http://localhost:3001/"
```

`.env.local` не се качва в git, затова на нов компютър редът с `echo` трябва да се пусне отново. Без него границите на държавите са грубите от оригинала.

Не са нужни API ключове. Без тях и без допълнителните сървъри на автора (Redis, seeders) някои панели остават празни и част от RSS източниците не се теглят — това е нормално при локално пускане.

## Подробните граници

Файлът `public/data/country-boundary-overrides-world.geojson` се прави от:

```bash
node scripts/fetch-world-boundary-overrides.mjs
```

Скриптът тегли Natural Earth 50m (около 24 MB) и записва 237 държави.

## Обновяване от оригинала

```bash
git fetch upstream
git merge upstream/main
```

Затова промените в този fork се държат малки и в малко файлове. Другите 27 езика не се пипат нарочно.
